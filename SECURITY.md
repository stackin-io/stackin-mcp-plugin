# Security policy

## Reporting a vulnerability

Email **support@stackin.io** with "Security" in the subject. Include what you found, how to reproduce it and what an attacker could do with it. Please do not open a public issue for a vulnerability.

We acknowledge reports within two business days and keep you posted until it is resolved.

## Scope

- The remote MCP server at `https://mcp.stackin.io/mcp`
- The Stackin API and OAuth authorization server it relies on (`api.stackin.io`)
- This plugin repository: manifests, skills and install instructions

Never send real API keys, certificates or fiscal documents in a report; describe them instead.
